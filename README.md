# CASE//UNKNOWN

A responsive neo-brutalist browser murder-mystery prototype.

## Run
Open `index.html` in a modern browser. No build step or backend is required.

## Core features
- Randomized murder case seed
- Randomized murderer, motive, weapon, time, secrets and red herrings
- Six connected investigation locations
- Interrogation with case-aware response logic
- Evidence collection
- Timeline reconstruction
- Sliding/tile-style and logic puzzles
- Maze/path deduction
- Multi-stage interconnected progression
- Final accusation with success/failure endings
- Desktop, tablet and mobile responsive layouts
- Touch swipe room navigation and keyboard arrow navigation
- Online photographic imagery from Unsplash URLs for atmosphere

## Note
This is a self-contained prototype. Online image/font requests require internet access. Replace remote assets with locally licensed assets if you plan to publish or distribute the project commercially.
